# Images Directory

## Logo

The `logo.svg` file is currently a placeholder. 

**To use the actual app icon:**
1. Download the app icon image from: https://github.com/user-attachments/assets/15d30fbf-6ec9-40fb-b87a-75a5b7ad20e8
2. Save it as `logo.png` in this directory
3. Update `index.html` line 23 to use `images/logo.png` instead of `images/logo.svg`

Alternatively, you can replace `logo.svg` with the actual app icon in SVG format.
